# News Authenticity Verification System Using Artificial Intelligence

## 1. Project Objective

The objective of this project is to develop an AI-based news authenticity verification system that analyzes news articles using Natural Language Processing and Machine Learning techniques to classify them as likely real or fake.

The system aims to help users identify potentially misleading news and improve awareness of misinformation.

## 2. Project Overview

The system accepts news article text as input, processes the text using NLP techniques, and applies a trained Machine Learning model to predict whether the news is likely real or fake.
